# AI Learning & Study Assistant

An AI-powered study assistant that helps students learn effectively through personalized study plans, course material-based Q&A, and interactive quizzes.

## Features

- 💬 AI-powered study assistant
- 📚 Course material Q&A using RAG
- 📝 AI-generated quizzes
- 📊 Quiz score and evaluation
- 📅 Personalized study plans
- 🧠 Memory for personalized learning
- 🛠️ AI tools and tool calling

## Technologies Used

- Python
- Streamlit
- LangChain
- RAG
- ChromaDB
- AI Agent & Tool Calling
